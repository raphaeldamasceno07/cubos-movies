# Cubos Movies

Projeto desenvolvido a partir do desafio técnico da Cubos Tecnologia.

Este repositório documenta o desenvolvimento de uma aplicação para gerenciamento de filmes, utilizando práticas de Engenharia de Software como levantamento de requisitos, modelagem, arquitetura, documentação e implementação.

O projeto é desenvolvido de forma incremental, simulando o fluxo adotado em projetos reais de software.

> Este README será atualizado conforme a evolução do projeto.
