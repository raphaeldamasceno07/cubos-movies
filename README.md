# Cubos Movies

Projeto desenvolvido a partir do desafio técnico da Cubos Tecnologia.

Este repositório documenta o desenvolvimento de uma aplicação para gerenciamento de filmes utilizando práticas de Engenharia de Software, desde o levantamento de requisitos até a implementação da solução.

O objetivo principal deste projeto não é apenas entregar uma aplicação funcional, mas demonstrar o processo de construção de software adotado em ambientes profissionais, enfatizando documentação, modelagem do domínio, arquitetura e boas práticas de desenvolvimento.

> **Observação:** O domínio desta aplicação é relativamente simples e poderia ser implementado utilizando uma arquitetura em camadas tradicional. Entretanto, este projeto adota conceitos de **DDD (Domain-Driven Design)** e **Clean Architecture** com finalidade educacional e de portfólio, permitindo estudar e demonstrar a aplicação dessas práticas em um projeto completo.

---

## Objetivos

- Aplicar conceitos de Engenharia de Software.
- Documentar todas as etapas do desenvolvimento.
- Modelar o domínio da aplicação antes da implementação.
- Aplicar princípios de DDD e Clean Architecture.
- Construir uma API escalável, desacoplada e testável.
- Desenvolver um projeto de portfólio seguindo um fluxo semelhante ao utilizado em equipes de desenvolvimento.

## Processo de Desenvolvimento

O projeto está sendo desenvolvido de forma incremental, seguindo uma abordagem semelhante à utilizada em equipes de Engenharia de Software:

1. Entendimento do problema.
2. Levantamento e documentação dos requisitos.
3. Modelagem dos casos de uso.
4. Modelagem do domínio.
5. Definição da arquitetura da solução.
6. Implementação do backend.
7. Implementação do frontend.
8. Testes, documentação e deploy.

Cada etapa é registrada neste repositório para demonstrar a evolução do projeto desde sua concepção até a entrega da aplicação.
